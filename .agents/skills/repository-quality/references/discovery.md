# Discovery

- Start with `AGENTS.md`, then use `docs/README.md` as the vault map.
- Locate code by reading the relevant manifest, entrypoint, route, schema, test, or direct search result. Treat source code, configuration, tests, and runtime output as authoritative.
- Find tests beside the workspace they cover: `apps/portfolio-web/tests/`, `workers/<worker>/tests/`, or `scripts/tests/` for shared repository-script tests. There is no root `tests/` directory.
- Read the relevant `.githooks/` scripts and `scripts/` validation commands when a change touches commits, hooks, or repository tooling.
- Read only the narrowest source and documentation context needed for the current task.
