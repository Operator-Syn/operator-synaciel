# Inspiration sources

Use these as curated search surfaces. Open only the source group relevant to the current decision, and record the principle taken from each selected example.

## Closest structural references

- [SiteInspire — Portfolio](https://www.siteinspire.com/websites/category/portfolio): filter by Portfolio, Minimal, Typographic, and Grid Layout for portfolio hierarchy and grid composition.
- [One Page Love — Minimal](https://onepagelove.com/style/minimal): inspect one-page pacing, hero-to-content transitions, and screenshotable layouts.
- [Minimal Gallery](https://minimal.gallery/): inspect restrained portfolios, agency pages, and one-page systems.
- [Httpster — Minimal](https://httpster.net/style/minimal/): inspect minimal, typographic, and brutalist-adjacent composition.
- [Siiimple](https://siiimple.com/): inspect negative space, type-led landings, and reduced visual vocabulary.

## Typography, darkness, and motion

- [Awwwards — Portfolio](https://www.awwwards.com/websites/portfolio/): inspect high-end portfolio structures and case-study narratives.
- [Awwwards — Minimal](https://www.awwwards.com/websites/minimal/): inspect hierarchy, whitespace, responsive composition, and typography.
- [Awwwards — Black](https://www.awwwards.com/websites/black/): inspect dark contrast systems and how accent colors are rationed.
- [Awwwards — Single Page](https://www.awwwards.com/websites/single-page/): inspect navigation and long-form sequencing.
- [Godly](https://godly.design/): inspect experimental interaction and art direction; borrow interaction principles, not spectacle.
- [CSS Design Awards — Minimal](https://www.cssdesignawards.com/website-gallery?feature=minimal): inspect combinations of minimal, grid, black, typographic, and one-page tags.

## Composition and landing-page references

- [Land-book](https://land-book.com/): inspect hero structures, content order, color relationships, and conversion patterns.
- [Lapa Ninja](https://www.lapa.ninja/): inspect hero sections, CTAs, page elements, and practical landing-page patterns.
- [Best Website Gallery](https://bestwebsite.gallery/): inspect complete live sites and unusual but usable compositions.
- [Dribbble — Developer Portfolios](https://dribbble.com/search/developer-portfolio): use for visual ideation only; verify behavior and implementation elsewhere.

## Selection rule

Choose at most three sources for a pass:

1. one structural reference;
2. one typographic or color reference;
3. one interaction reference only if motion is genuinely needed.

Do not combine incompatible visual grammars without naming the reason. A source can answer “how should this section be paced?” without becoming the page's entire aesthetic.
