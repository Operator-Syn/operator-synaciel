## Reference method

1. Pick two or three references that answer the current design question; do not collect a moodboard with no decision attached.
2. Extract principles: hierarchy, density, alignment, type contrast, color temperature, motion timing, and content behavior.
3. Translate those principles into the product's content and constraints.
4. Reject anything that is only decorative, difficult to maintain, inaccessible, or visibly copied.
5. Record the decisions in the visual contract before implementation.

## Anchor reference

[Francis Kyle Lorenzana portfolio](https://franciskylelorenzana.vercel.app/) is the anchor for this skill's initial direction. Treat it as a study in dark editorial/neo-brutalist portfolio composition: oversized two-tone typography, cream-black-amber contrast, indexed sections, thin rules, technical diagram-like motifs, one-page case-study flow, and restrained motion. Re-check the live page when it is available; this description is a design abstraction, not a claim that every implementation detail remains unchanged.
